---
title: "Bartr: Item Trading Platform"
date: "2025-06-20"
description: "A simple web application for trading items between users."
---

The proposed solution is BARTR, a dynamic web-based item trading platform built using Python and Flask, paired with SQLAlchemy for seamless MySQL database management. Designed with a modular and service-oriented architecture, BARTR enables secure, direct item exchanges between users through real-time in-app messaging, alongside robust administrative tools for platform governance and transaction moderation.
