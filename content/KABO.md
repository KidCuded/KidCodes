**KABO** is a customer loyalty and review platform designed to help businesses engage customers, streamline review collection, and manage subscription-based loyalty incentives. 

Built with a modern serverless stack, KABO combines **Next.js**, **React**, **Tailwind CSS**, and **Supabase** for backend services and authentication. The application features automated subscription workflows integrated with payment gateways (such as CHIP and Razorpay Curlec), along with real-time push notification support using Apple Push Notification service (APNs) keys. 

### Key Features & Architecture
- **Full-Stack Next.js & Supabase Engine:** Leverages Next.js App Router for server-rendered performance and Supabase for real-time database management, authentication, and secure access control.
- **Payment & Subscription Integration:** Handles recurring customer subscriptions and automated payment processing via local gateway integrations.
- **Push Notification Pipeline:** Configured with APNs key authentication for real-time customer re-engagement and review prompts.
- **Modern UI/UX:** Styled using Tailwind CSS to provide a clean, responsive interface for both end-users and merchant dashboards.
