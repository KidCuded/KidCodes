The proposed solution is a Point-of-Sale (POS) system made with the programming
language Java which combines desktop touchscreen user interface with service
oriented backend to make transactions processing secure, efficient and reliable. This
system is created based on JavaFX as its frontend and Spring Boot as its backend
services, which allows it to be designed in a modular way, with a scalable and
maintainable character.
