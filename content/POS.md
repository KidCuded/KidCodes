**KIDPOS** is a robust Point-of-Sale (POS) application engineered to make transaction processing secure, efficient, and highly reliable. Designed with a service-oriented architecture, it bridges a responsive desktop touchscreen interface with a powerful backend server.

Developed as a comprehensive full-stack Java application, KIDPOS utilizes **JavaFX** for its modular frontend and **Spring Boot** connected to a **MySQL** database for its backend services. This clear separation of concerns ensures the system remains scalable, easily maintainable, and adaptable for demanding retail environments.

### Key Features & Modules
- **Rule-Based Fraud Detection Engine:** Actively monitors and analyzes transaction behaviors and database logs to flag anomalies and prevent fraudulent activity in real-time.
- **Touchscreen-Optimized UI:** A modern, desktop-native user interface built with JavaFX, designed specifically for rapid interactions and ease of use in fast-paced retail settings.
- **Service-Oriented Architecture (SOA):** Leverages Spring Boot to create independent backend services that securely manage data flow, business logic, and API communication.
- **Relational Database Architecture:** Utilizes MySQL to efficiently map complex entity relationships, securely storing transaction histories, inventory data, and user profiles.
- **Scalable Transaction Processing:** Ensures high reliability during checkout flows, built modularly so that new features or hardware integrations can be deployed without disrupting core operations.
